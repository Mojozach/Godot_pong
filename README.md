# Neon Pong

Neon Pong is a simple 2D arcade game created using the Godot game engine and GDScript. The game features a dark background, neon-colored paddles, a bouncing ball, and a score counter. The player controls the left paddle using the W and S keys, while the right paddle is controlled by a basic computer opponent. The game also includes background music and sound effects when the ball collides with paddles or the walls.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download and install the Godot game engine.
2. Open the Neon Pong project in Godot.
3. Make sure the background music and sound-effect MP3 files are included in the project and assigned to the correct audio players.
4. Open the main scene and click the Play button to run the game.

Instructions for using the software:

1. Start the game and listen to the background music.
2. Use the W key to move the left paddle up and the S key to move it down.
3. Try to hit the ball past the computer-controlled paddle to score points. Prevent the ball from passing your paddle to stop the computer from scoring.
4. Listen for sound effects when the ball hits a paddle or the top and bottom walls.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Godot Engine 4.x.
* GDScript, the scripting language used by Godot.
* A computer running Windows, macOS, or Linux.
* MP3 audio files for background music and sound effects.
