# Neon Pong

Neon Pong is a simple 2D Pong game created using the Godot game engine. The game features two paddles, a bouncing ball, and a score counter. The left paddle is controlled by the player using the W and S keys, while the right paddle is controlled by a basic computer opponent. The game uses a dark background with neon-colored paddles to give it a retro arcade appearance.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download and install the Godot game engine.
2. Open the Neon Pong project in Godot.
3. Open the main scene and click the Play button to run the game.

Instructions for using the software:

1. Start the game and wait for the ball to begin moving.
2. Use the W key to move the left paddle up and the S key to move it down.
3. Try to hit the ball past the computer-controlled paddle to score points. Prevent the ball from passing your paddle to keep the computer from scoring.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Godot Engine 4.x or a compatible version.
* GDScript, the scripting language used by Godot.
* A computer running Windows, macOS, or Linux.
